# Sweet3D

A web version of [Sweet Home 3D](https://www.sweethome3d.com) that runs entirely in the browser:
no server, no login, no database. Projects are stored in the browser's IndexedDB and can be downloaded
as `.sh3d` files and exchanged with the desktop app.

> **A hobby project.** Sweet3D is a personal hobby project, not a commercial product, and it is not affiliated
> with Sweet Home 3D or its authors. **100% of the code was generated by [Claude](https://claude.ai)**
> (Anthropic's AI) via Claude Code.
>

> ideas or questions, or send a [pull request](https://github.com/Paul6552/sweet3D/pulls).

## Development

```bash
npm install
npm run dev     # http://localhost:5173, generates the catalog first
npm run build   # static site in dist/
npm run lint
```

`npm run catalog` regenerates the catalog (only needed when the JARs in `vendor/sh3d` are replaced;
`dev` and `build` do this automatically whenever something has changed).

## Self-hosting

After `npm run build`, `dist` is a static site that runs on any web server. For the `/editor/...` URLs the
server must answer unknown paths with `index.html` (see `nginx.conf`).

With Docker (nginx):

```bash
docker compose up -d --build   # http://localhost:8180
```

## Projects and files

- On startup the editor opens directly with the most recently edited project (a new one the first time).
- Via the folder icon at the top left: create, open, rename, duplicate and delete projects, and import `.sh3d` files.
- Changes are saved automatically in the browser (IndexedDB). Imported models are stored there as files;
  browsers usually allow a large share of the free disk space. Usage and available space are shown in the
  projects dialog. `localStorage` (only about 5 MB) is used for small settings only.
- Download as `.sh3d` via the download icon in the toolbar or in the projects dialog.
  The file contains `Home.xml` and the models and opens in Sweet Home 3D 5.3 or later.
- Import: files from Sweet Home 3D 5.3 or later. Furniture from the default catalog uses its models, other models
  are copied into the project (OBJ). Levels, dimension lines, texts, colors, textures, compass and time of day are
  imported and exported again. Shelf units (`shelfUnit`) are imported as regular furniture, without their shelves.
- Dimension lines (M): click start and end, then set the offset with the mouse; they snap to corners.
  Texts (T): click the desired position and type the text.
- Properties: double-clicking in the plan or the furniture list, or the pencil in the toolbar, edits the
  selection, also several objects at once. Wall sides, floors, ceilings and furniture get a color or a texture
  from the catalog, from the project or from your own image.
- The project list shows a thumbnail that the 3D view updates after every change.
- Levels: tabs above the plan select the level, "+" adds a new one above the top level, double-clicking a tab
  edits name, elevation, height, floor thickness and visibility or deletes the level. The plan shows the level
  below faded; like Sweet Home 3D, the 3D view shows the selected level and all levels below it.
- Sun and lighting: the compass sets north direction, latitude, longitude and time zone; date and time in the
  3D toolbar set the position of the sun. Rooms are lit through their windows and by their lights; "Rooms always
  bright" in the sun settings helps while furnishing.
- Language: German or English, or the browser language (settings menu at the top right).
- Data belongs to the browser and the address of the page: another browser or computer cannot see it.
  Download the `.sh3d` file to back up or share a project.

## Views on multiple screens

Each panel (furniture catalog, furniture list, plan, 3D view) can be detached into its own window via the ↗ icon,
e.g. the 2D plan on screen 1 and the 3D view on screen 2.

- In Chrome and Edge the app asks once for the *Window management* permission and then offers the target
  screen. Position and size of each window are remembered.
- The windows synchronize via `BroadcastChannel`. The main window applies all changes, saves automatically and
  distributes them as immer patches. Undo/redo (Ctrl+Z / Ctrl+Y) works in every window.
- When a panel window is closed or brought back via ↙, the panel reappears in the main window.
  After a reload the toolbar offers "Restore windows".
